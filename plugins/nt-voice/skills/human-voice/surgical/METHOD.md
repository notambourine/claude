# Surgical edit

Preserve facts, numbers, names, citations, claims, structure, register, and defensible voice.
Edit phrasing only. Uncertain: keep.

Read whole piece; note voice; collect candidates; validate meaning/intent; edit minimally;
reread rhythm; report changed tell categories. For drafting: write first, then review.

| Tell | Fix |
| --- | --- |
| Throat-clearing, importance flags | State consequence. |
| Vague `This/That` kicker | Cut or join. |
| Puffery, intensifiers, grand claims | Cut or scope. |
| Clever metaphor | State plainly. |
| Forced three-item rhythm | Keep true items. |
| Repeated antithesis/correlatives | Simplify. |
| Hedging | Commit or cut. |
| Closing summary | Cut repetition. |
| AI lexicon | Plain word or deletion. |

Keep earned fragments, deliberate parallelism, strong closings, owned first-person
conviction. Stop when remaining candidates are voice. Never replace one formula with
another. Detailed disputes: [references/tells.md](references/tells.md).
