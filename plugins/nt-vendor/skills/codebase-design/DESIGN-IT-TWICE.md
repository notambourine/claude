# Design it twice

For a chosen deepening candidate:

1. Show constraints, dependency categories, and an illustrative non-proposal sketch.
2. Spawn at least three parallel agents with separate briefs and common domain/design terms:
   minimal 1-3-entry interface; maximal flexibility; trivial common path; ports/adapters when
   applicable.
3. Require each: full interface contract, usage, hidden implementation, dependencies and
   adapters, leverage tradeoffs.
4. Present sequentially. Compare depth, locality, seam placement.
5. Recommend one or a concrete hybrid.

Use [SKILL.md](SKILL.md), [DEEPENING.md](DEEPENING.md), and project `CONTEXT.md` terms.
